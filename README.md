# 華子さん（小泉華子）プロジェクト

思考の学校 上級認定講師・小泉華子（はなちゃん）の集客コンテンツ。
YouTube「はなまるチャンネル」／キャッチコピー「自分にダメ出しより花丸を！」

## ファイル

| ファイル | 中身 |
|---|---|
| `hanaichimonme.html` | はないちもんめセラピー。チャット型診断（選択肢8つ→結果4タイプ）。ゴールはLINE友だち追加 |
| `対談の型.html` | タイプ別対談の型。キャスト・事前準備・20分の流れ・締め方・やらないこと |
| `語り口メモ.md` | 華子さんのYouTube文字起こしから抽出した語り口の型。原稿はこれ基準で書く |
| `hanako-avatar.jpg` | チャットのアイコン（公式サイトのプロフィール写真） |
| `og-b.png` | **採用中**のSNSシェア用カード 1200×630（元データ `og-card-b.html`） |
| `og.png` | 不採用のA案（4タイプ並べ。元データ `og-card.html`） |
| `img/hanaichi.png` | はないちもんめの情景イラスト原本（`-trim`は余白を詰めたもの、`.jpg`がWeb用） |
| `og-banner.png` | 旧・縦長バナー（8択時代のもの。未使用） |
| `hanako.png` | 写真バナー素材 |
| `img/type1〜4.png` | タイプ別イラスト原本（.jpgはWeb用に640pxへ軽量化したもの。HTMLは.jpgを参照） |
